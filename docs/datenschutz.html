für die App „Shorts Zentrale“ und diese Website. Stand: 1. November 2026.

Diese Website

Die Website wird über GitHub Pages ausgeliefert. GitHub verarbeitet dabei technisch nötige Daten wie die IP-Adresse, um die Seite auszuliefern (Datenschutzerklärung von GitHub).

Die Website setzt keine Cookies, nutzt kein Tracking und keine Werbung. Schriften, Vorschaubilder und der animierte Film liegen auf derselben Website; beim Öffnen wird nichts von YouTube oder anderen Diensten geladen.

Erst wenn du ein Video antippst, lädt der YouTube-Player im erweiterten Datenschutzmodus (youtube-nocookie.com). Dann gelten die Regeln von Google und YouTube.

Wer die App nutzt

Die App ist ein privates Werkzeug für einen einzigen, eigenen YouTube-Kanal. Sie läuft auf einem privaten Heimserver und wird nicht an andere Personen angeboten.

Welche Daten die App verwendet

Über die YouTube API Services erhält die App nach der Anmeldung mit Google Zugriff auf den verbundenen YouTube-Kanal. Sie nutzt diesen Zugriff nur, um:

  • eigene Videos hochzuladen,
  • Kanalbanner und Kanalbeschreibung zu setzen,
  • den Kanalnamen, die Abonnentenzahl und die Aufrufe der eigenen Videos anzuzeigen,
  • über die YouTube Analytics API zusammengefasste Werte zu den eigenen Videos anzuzeigen: durchschnittliche Wiedergabedauer und wie viel Prozent der Zuschauer an welcher Stelle eines Videos noch zusehen. Diese Werte sind anonym und enthalten keine Angaben zu einzelnen Zuschauern.

Die App liest keine Daten anderer Nutzer, keine Kommentare und keine privaten Nachrichten.

Wo die Daten gespeichert werden

Der Zugangsschlüssel von Google und die Statistiken werden nur auf dem privaten Server des Kanalbetreibers gespeichert. Es gibt keine Datenbank im Internet, keine Weitergabe an Dritte, keine Werbung und kein Tracking.

Zugriff widerrufen

Der Zugriff lässt sich jederzeit in der App mit „Kanal trennen“ beenden oder in den Google-Kontoeinstellungen unter myaccount.google.com/permissions entziehen. Für die Zuschauer-Daten gibt es einen eigenen Knopf „Zuschauer-Daten trennen“. Beim Trennen wird der gespeicherte Zugangsschlüssel vom Server gelöscht.

Google und YouTube

Die App nutzt die YouTube API Services. Es gelten die YouTube-Nutzungsbedingungen und die Datenschutzerklärung von Google.
