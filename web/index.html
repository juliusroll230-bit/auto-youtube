    YouTube-Verbindung

    Google-Zugang

    Wird nur auf deinem Server gespeichert.
    So bekommst du Client-ID und Clientschlüssel
    1. Mit dem Google-Konto deines Kanals ein Projekt anlegen.
    2. YouTube Data API v3 aktivieren.
    3. Unter Google Auth Platform starten: App-Name z. B. „Shorts Zentrale“ (ohne „YouTube“ oder „Google“, das lehnt Google ab), Zielgruppe Extern. Danach unter Zielgruppe → Testnutzer das Google-Konto deines Kanals eintragen.
    4. Unter Clients einen Client vom Typ „Fernseher und Geräte mit begrenzter Eingabe“ erstellen.
    5. Client-ID und Clientschlüssel hier eintragen.

    Zeitplan

    Sendezeiten (deutsche Zeit, bis zu 6 pro Tag)
    Neue Google-Projekte laden zunächst nur privat hoch, bis YouTube das Projekt geprüft hat.

    Aktionen

    Nimmt das nächste Video aus dem Sendeplan.
    Passiert sonst alle 2 Stunden.
