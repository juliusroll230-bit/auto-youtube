          YouTube gibt die Daten, wann Zuschauer abschalten, nur über eine eigene Schnittstelle heraus. Dafür braucht die Shorts-Zentrale einen zweiten Zugang. Dein Upload-Zugang bleibt, wie er ist.

          1. In Google Cloud die YouTube Analytics API öffnen und auf Aktivieren klicken. Oben muss dein Projekt ausgewählt sein.
          2. Unter Google Auth Platform → Clients auf Client erstellen klicken, Typ Webanwendung. Bei Autorisierte Weiterleitungs-URIs diese Adresse eintragen:
            –
          3. Client-ID und Clientschlüssel des neuen Clients hier eintragen: ✓ schon gespeichert
          4. Auf Verbinden klicken und mit dem Google-Konto deines Kanals anmelden. Zeigt Google „App wurde nicht überprüft“, auf Erweitert und dann Weiter tippen.

            2. YouTube Data API v3 aktivieren.
            3. Unter Google Auth Platform starten: App-Name z. B. „Shorts Zentrale“ (ohne „YouTube“ oder „Google“), Zielgruppe Extern.
